# Rubik Sliding Board Game

An n x n sliding puzzle game in Java Swing where rows and columns shift circularly like a Rubik's cube.

## Features

- Circular row and column shifts (left, right, up, down)
- Random shuffle to generate starting position
- Solved-state detection
- Clean separation of logic (RubikBoard) and rendering (BoardPanel)
- Difficulty selection
- JUnit tests for core game logic

## Tech Stack

Java, Java Swing, JUnit, Maven

## How to Run

1. Make sure you have Java 17+ and Maven installed
2. Run: `mvn compile exec:java`
